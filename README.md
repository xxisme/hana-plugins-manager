# 小花插件管理（hana-plugins-manager）

> **版本：0.10.4** · 管理本机 Hana 插件的完整工具

在一个页面内完成插件的全生命周期管理：列表、安装、更新、卸载、启停、备份、GitHub 关联与上游版本检测。

---

## 功能特性

| 模块 | 说明 |
|---|---|
| **插件管理** | 已装插件列表（名称/版本/权限/启停状态）、详情抽屉、启停切换、卸载（卸载前自动备份） |
| **GitHub 关联** | 每个插件可关联上游 GitHub 仓库，关联后「更新」Tab 自动检测新版本 |
| **安装** | 两种来源：GitHub 地址解析下载；本地 zip / 文件夹导入（文件浏览器支持跨盘符）。GitHub 安装优先取 **Release 发布包**（作者打包的构建产物，含真实入口），无可用 Release 资产时自动回退源码；安装面板会标注实际来源 |
| **更新** | 批量检测已关联插件的上游版本，勾选后逐个更新；更新前自动备份旧版本，失败可回退 |
| **备份还原** | 全量备份（自动保留最近 5 份，超出删除最早的）、备份备注与删除；还原功能灰度测试中，可临时用常规安装方式还原 |
| **操作日志** | 每次安装/更新/卸载/启停/备份等操作落盘记录，可追溯 |
| **可安装插件** | 从社区插件清单（github.com/xxisme/hana-plugins-manager）拉取未安装项目，点击卡片自动填入安装地址 |
| **风险预检** | 安装/更新前扫描 manifest 与源码（full-access 权限、敏感能力、minAppVersion 兼容性、可疑代码模式），给出风险等级 |

## 页面使用

### 插件管理
- 插件卡片展示名称、版本、权限标签（完全访问 / 受限）、启停开关
- 点卡片打开详情抽屉：查看 manifest、编辑 GitHub 关联、卸载插件
- 右上角可切换 Hana 主目录（多 Hana 环境）

### 安装
- **GitHub 地址**：粘贴仓库地址 → 解析并下载 → 风险检测 → 继续安装；合集仓库会列出全部候选插件供选择
  - **Release 优先**：若仓库有作者上传的 zip 发布包（过滤 GitHub 自动生成的 Source code 源码包），优先下载 Release 包——它是作者打包的构建产物，避免源码项目"装上但打不开"；无可用 Release 资产时自动回退源码 zip
  - 安装面板的「来源」行会标注实际来源（Release 发布包 / GitHub 源码），请留意
- **本地 zip / 目录**：输入路径或点「浏览」选择文件（支持跨盘符到其他磁盘）；zip 解压后自动定位插件根目录
- **可安装插件**：页面底部从社区清单拉取未安装项目，点击卡片自动填入上方地址栏，再点「解析并下载」继续

### 更新
- 列表显示本地版本 → 远端版本；已关联仓库的插件可检测更新
- 「重新检测」强制刷新（跳过缓存）；检测失败会给出原因（404 / 限流 / 无 version）
- 匿名 GitHub API 限流 60 次/小时，检测频繁请配置 Token（见下方配置）

### 备份还原
- 「全量备份」把整个插件目录打包保存；列表支持备注与删除
- 还原功能灰度测试中，暂不可用；可用常规安装方式（安装页导入备份目录下的插件文件夹）还原

## Agent 工具

安装本插件后，Agent 获得 5 个对话内可直接调用的工具：

| 工具 | 说明 |
|---|---|
| `hana_list_plugins` | 列出本机插件及状态 |
| `hana_install_plugin` | 安装插件（GitHub 地址或本地 zip/目录） |
| `hana_uninstall_plugin` | 卸载插件 |
| `hana_toggle_plugin` | 启用 / 停用插件 |
| `hana_update_plugin` | 更新插件到上游最新版本 |

## 配置

### GitHub Token（推荐）
更新检测与私有仓库访问需要 GitHub API。匿名限流 60 次/小时，配置 Token 后提升到 5000 次/小时。

申请步骤：`github.com/settings/tokens` → Generate new token (classic) → 勾选 `repo` 权限 → 生成 `ghp_...` → 在插件「更新」页点「配置 Token」粘贴保存。Token 仅保存在本机插件数据目录，不会上传。

### Hana 主目录
默认自动探测 `~/.hanako`，也可通过环境变量 `HANA_HOME` 或插件配置项 `hanaHome` 指定。

---

## 数据目录

插件运行数据保存在 `<HANA_HOME>/plugin-data/hana-plugins-manager/`：

| 文件/目录 | 说明 |
|---|---|
| `plugin-sources.json` | 插件 → GitHub 仓库关联记录 |
| `plugin-backups.json` | 备份清单元数据 |
| `backups/plugins/<时间戳>/` | 每次备份的插件快照 |
| `github-token` | GitHub Token（明文，权限 600，仅本机可读） |
| `operations.log` | 操作日志（每行一条 JSON） |
| `tmp/` | 安装/更新临时工作目录（退出时清理） |

## 安全说明

- 安装/更新前会做**格式与行为预检**（非安全审计）：标记 full-access、敏感能力、可疑代码模式，提示风险等级；高风险插件安装需手动确认
- 社区清单里的插件**未经检测与测试**，安装前请自行评估来源可信度
- 插件可声明 `full-access`（完全访问权限），只安装信任来源的插件
